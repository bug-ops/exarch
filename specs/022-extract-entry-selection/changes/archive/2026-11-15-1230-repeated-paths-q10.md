# Delta: plan Q10 under the opt-in Refuse policy (#1201)

## MODIFIED

### Q10 (plan.md)

Old: "Collisions after strip or flatten follow `ExistingFiles` (see FR-020 in the spec): `Skip` first wins and counts a duplicate, `Overwrite` replaces where kinds allow, `Refuse` refuses an occupant the run did not create | No new default"

New: unchanged by default (`RepeatedPaths::KeepFirst`). Under the opt-in `RepeatedPaths::Refuse` a collision after strip or flatten that lands on an occupant the run made is refused with `Violation::RepeatedPath` under every `ExistingFiles` mode; a deselected copy is never a repeat; an occupant whose maker cannot be proven is refused as `DestinationOccupied { by: Existing }`. No new default ([[030-duplicate-entry-repeated-paths/spec]]).
